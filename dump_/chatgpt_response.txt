9A. Maximum Drawdown
Definition

Maximum Drawdown (MDD) is the largest percentage decline from a historical peak to a subsequent trough.

Python Solution
def max_drawdown(prices):
    peak = prices[0]
    max_dd = 0.0

    for price in prices:
        peak = max(peak, price)
        drawdown = (peak - price) / peak
        max_dd = max(max_dd, drawdown)

    return max_dd


prices = [100, 120, 115, 130, 90, 95, 140]

print(max_drawdown(prices))
Output
0.3077

Maximum Drawdown = 30.77%

(130 → 90)

Complexity

Time Complexity:

O(n)

Space Complexity:

O(1)

9B. Efficient 5-Minute Moving Average

For large tick datasets:

Approach

Use a sliding window.

Maintain:

Queue of observations
Running sum
Algorithm
from collections import deque

window = deque()
running_sum = 0

for tick in ticks:

    timestamp, price = tick

    window.append((timestamp, price))
    running_sum += price

    while timestamp - window[0][0] > 300:
        old = window.popleft()
        running_sum -= old[1]

    moving_avg = running_sum / len(window)
Complexity

Time: O(n)

Space: O(w)

where w is window size.
