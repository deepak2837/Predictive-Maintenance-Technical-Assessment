# Predictive Maintenance Technical Assessment

Technical exercise on the AI4I 2020 predictive-maintenance dataset: exploratory analysis, feature engineering and machine-failure classification.

## Contents
- `Technical_Exercise_Gayatri_Masu.ipynb` — the full analysis notebook (EDA, modelling, evaluation)
- `ai4i2020.csv` — the AI4I 2020 predictive maintenance dataset
- `Gayatri_Masu_Assessment.docx` — the written assessment brief / summary
- `dump_/` — intermediate working artefacts
